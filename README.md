# Читальня — обновлённая версия сайта

Статический сайт литературного клуба. Используются только HTML, CSS и JavaScript без сборщика, фреймворков и серверной части. Подходит для GitHub Pages.

## Что изменено

- Главная страница получила более выразительную редакционную композицию в прежней тёплой палитре.
- Книга теперь раскрывается в ходе прокрутки страницы: анимация 3D-обложки, масштаб книги, раскрытие разворота и появление текста связаны с прогрессом прокрутки.
- На небольших экранах книга превращается в одностраничную сцену, чтобы текст оставался читаемым.
- Сохранены архив встреч, поиск, сортировка, просмотр фотографий, редактор, черновики в `localStorage`, импорт/экспорт JSON.
- Основная иллюстрация — локальный SVG; тяжёлые библиотеки и удалённые изображения не используются.
- Учтена системная настройка `prefers-reduced-motion`.

## Локальный запуск

Из-за загрузки JSON через `fetch()` нельзя открывать `index.html` двойным щелчком (`file://`). Запустите локальный сервер из корня проекта:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`.

## Публикация на GitHub Pages

1. Загрузите содержимое папки проекта в корень репозитория (не саму папку `chitalnya-redesign`).
2. В GitHub откройте **Settings → Pages**.
3. В качестве источника выберите нужную ветку и каталог `/ (root)`.
4. Сохраните настройки и откройте опубликованный адрес.

Все ссылки на CSS, JS, данные и изображения относительные — сайт рассчитан также на публикацию в подпапке GitHub Pages.

## Редактор

Откройте `editor.html` на опубликованном сайте. Изменения сохраняются как локальный черновик в браузере организатора. Кнопка экспорта скачивает `chitalnya-data.json`; для публикации замените им файл `data/chitalnya-data.json` в репозитории и сделайте commit.

Изображения можно встроить в JSON (подходит только для небольших файлов) или скачать сжатым JPG и отдельно загрузить в `assets/images/`. Редактор не отправляет файлы на GitHub автоматически: у статического сайта нет серверных полномочий на запись в репозиторий.

## Проверка

- Откройте `index.html`, прокрутите раздел с книгой от начала до конца: обложка должна плавно раскрыться, разворот и текст — проявиться.
- Проверьте страницу истории, поиск, сортировку и просмотр фотографий.
- Откройте редактор, измените поле, добавьте встречу, экспортируйте JSON и импортируйте его обратно.
- Проверьте мобильный вид и системный режим уменьшения движения.
