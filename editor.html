Как добавить изображения

Можно встроить небольшое фото в JSON, но это увеличит размер данных. Рекомендуется скачать сжатое фото отдельно и загрузить его в assets/images/ репозитория. Редактор не отправляет файлы на GitHub автоматически.

Предпросмотр

Предпросмотр обновляется автоматически при изменениях.

Экспорт и импорт данных

Как опубликовать изменения:
  1. Откройте репозиторий на GitHub.
  2. Замените файл data/chitalnya-data.json скачанным JSON.
  3. Если добавляли изображения, загрузите их в assets/images/.
  4. Нажмите Commit changes. GitHub Pages обновит сайт автоматически.
Как устроено хранение

Черновик автоматически сохраняется в браузере. Посетители видят только JSON из репозитория. Экспорт скачивает файл, но не отправляет изменения на GitHub.
